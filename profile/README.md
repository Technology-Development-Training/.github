## What we do

| Domain | In one line |
| :--- | :--- |
| **Software Production Automation** | We treat software as a production line — code generation, agent pipelines, template systems and CI that turn a spec into a shipped artifact. |
| **Social Content** | Engines that create, schedule and distribute content at scale, with generation and publishing in a single loop. |
| **Multimedia App** | Apps that create, process and understand media — imaging, video and audio across desktop and mobile. |
| **Game** | Interactive entertainment: game systems, the content pipeline behind them, and player-facing experiences. |

The through-line is the same in all four: **anything done twice by hand becomes a tool the third time.**

## How we build

The rules the work holds to, regardless of which domain it lands in:

- **Automation is the product, not the cleanup.** If a step is repeated, it gets scripted, templated or generated.
- **Reproducible beats clever.** A build you can repeat is worth more than a build you have to remember.
- **One baseline, four outputs.** Shared tooling, shared review, shared release discipline — the domain changes, the standard does not.
- **Training is part of shipping.** The harness, the templates and the docs are how the standard travels to the next person.
